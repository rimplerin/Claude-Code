# 🍌 Banana i2i

Google Vertex AI의 **Nano Banana 2 / Nano Banana Pro**(Gemini 이미지 모델)로 이미지→이미지(i2i) 작업을 하는 로컬 웹앱입니다.

1. **캐릭터 변환**: 실사 사진 속 인물을 만화 캐릭터로 바꾼 2D 일러스트를 만듭니다.
   - 사진 한 장에 여러 명이 있어도 **어떤 인물 → 어떤 캐릭터**인지 지정할 수 있습니다. 사진 위를 드래그해 박스를 그리거나, 위치(왼쪽/가운데/오른쪽/앞/뒤)를 고르거나, "빨간 원피스 입은 여자"처럼 설명을 적으면 됩니다.
   - 인물마다 **캐릭터 옷 / 실사 옷**을 고를 수 있습니다.
   - 사진을 여러 장 한꺼번에 올려 동시에 처리합니다.
2. **만화 채색**: 흑백 만화 페이지를 공식 디지털 컬러판처럼 채색합니다. 라이브러리 캐릭터를 색상 참조로 넣으면 머리, 눈, 옷 색을 맞춥니다.
3. **인페인트**: 바꿀 영역(빨강)과 프롬프트를 지정해 일부만 수정합니다. 참조 이미지를 함께 넣을 수 있습니다.
4. **자유 모드**: 프롬프트와 이미지(0~14장)를 그대로 Nano Banana에 보냅니다. 여러 이미지에 같은 프롬프트를 따로 적용할 수도 있습니다.
5. **마스킹** (인페인트, 만화 채색): 검열에 걸릴 만한 부분을 칠해 두면 그 부분을 가린 채로 요청합니다. 결과가 나오면 그 영역만 원본으로 되돌려 붙입니다. 이미지는 지원 비율로 여백을 붙여 보냈다가 결과에서 잘라내므로 위치가 정확히 맞습니다.
6. **캐릭터 라이브러리**: 캐릭터 참조 이미지를 미리 저장해 두고 작업할 때 고르기만 하면 됩니다.

## 실행 방법

필요한 것은 [Node.js](https://nodejs.org) LTS(20.18 이상) 하나입니다.

- **Windows**: `start.bat` 더블클릭
- **macOS / Linux**: `./start.sh`
- 직접 실행: `npm install` 후 `npm start` → 브라우저에서 http://localhost:3000

`start.bat`은 PC의 PATH 환경 변수가 망가져 있어도(예: `'chcp'은(는) 내부 또는 외부 명령...이 아닙니다` 오류) Windows 시스템 폴더와 기본 Node.js 설치 폴더를 직접 찾아서 실행합니다. 그래도 Node.js를 못 찾는다고 나오면 Node.js 설치 후 PC를 재시작하세요.

처음 실행하면 설정 탭이 열립니다. 서비스 계정 JSON 키를 등록하고 **연결 테스트**를 누르세요.

## Google Cloud 서비스 계정 키 만들기

Vertex AI는 API 키 대신 서비스 계정 JSON(`project_id`, `private_key_id`, `private_key` …)으로 인증합니다.

1. [Google Cloud Console](https://console.cloud.google.com)에서 크레딧이 있는 프로젝트를 선택합니다.
2. **API 및 서비스 → 라이브러리**에서 **Vertex AI API**를 사용 설정합니다.
3. **IAM 및 관리자 → 서비스 계정 → 서비스 계정 만들기**를 누르고 역할을 **Vertex AI 사용자(roles/aiplatform.user)**로 줍니다.
4. 만든 서비스 계정에서 **키 → 키 추가 → 새 키 만들기 → JSON**을 고릅니다. 다운로드된 파일을 앱 설정 탭에 끌어다 놓습니다.

키는 이 PC의 `data/credentials.json`에만 저장되고 브라우저로 다시 보내지 않습니다. `.gitignore`에도 들어 있습니다.

### 모델 ID

| 이름 | 기본 ID |
| --- | --- |
| Nano Banana 2 | `gemini-3.1-flash-image` |
| Nano Banana Pro | `gemini-3-pro-image` |

리전(location) 기본값은 `global`입니다. 연결 테스트에서 404(모델 없음)가 나오면 설정 탭에서 ID를 바꾸세요. 예를 들어 `-preview`가 붙은 ID를 쓸 수 있습니다. 앞으로 Google이 ID를 바꿔도 코드는 고치지 않아도 됩니다.

## 오류와 차단 처리

| 상황 | 앱의 처리 |
| --- | --- |
| `fetch failed`, 연결 끊김, 시간 초과, 5xx | 지수 백오프로 자동 재시도 (기본 6회) |
| 429 / RESOURCE_EXHAUSTED (분당 한도) | `Retry-After`를 따르고 **큐 전체를 잠시 멈췄다가** 자동으로 재개 |
| 안전 필터 차단, 이미지 없이 텍스트만 응답 | 같은 요청을 다시 보냄 (기본 3회, 결과가 매번 달라 재시도로 통과되는 경우가 많음) |
| 401/403/404/400 | 재시도하지 않고 원인과 해결 방법을 표시 |

- 안전 설정 4종(혐오, 위험, 성적, 괴롭힘)은 모두 `OFF`로 보냅니다. 모델이 `OFF`를 거부하면 자동으로 `BLOCK_NONE`으로 바꿉니다.
- `PROHIBITED_CONTENT`, `IMAGE_SAFETY` 같은 Google의 기본 보호 필터는 API 설정으로 끌 수 없습니다. 그래서 자동 재시도로 대응합니다.
- 동시 작업 수, 분당 요청 수, 재시도 횟수, 타임아웃은 설정 탭에서 조절합니다. 429가 자주 나오면 분당 요청 수를 낮추세요.
- 큰 사진은 브라우저에서 긴 변 2048px(만화는 2560px)로 줄여서 보내므로 전송 실패가 줄어듭니다.
- 작업 큐와 결과는 `data/`에 저장됩니다. 서버를 껐다 켜도 남아 있고, 진행 중이던 작업은 다시 큐에 들어갑니다.

## 사용 팁

- **헤어스타일이 실사 인물을 따라갈 때**: 라이브러리에서 캐릭터의 **외형 분석**을 실행하세요. 새 캐릭터는 저장할 때 자동으로 분석됩니다. AI가 헤어, 눈, 의상을 글로 정리해 두면 그 내용이 변환 프롬프트의 HAIR LOCK과 최종 점검 항목에 들어갑니다. 분석 결과는 직접 고칠 수 있습니다.
- **기타 옵션**: 캐릭터 변환 탭의 "옵션 추가 / 편집"에서 텍스트 제거, 로고 제거, 맨발 같은 규칙을 원하는 만큼 만들 수 있습니다. 사진 카드마다 켜고 끌 수 있고, "모두 켬/끔"으로 한 번에 바꿀 수도 있습니다.

- **여러 명 사진**: 인물 행을 클릭해 선택한 뒤 사진 위를 드래그하면 그 인물의 박스가 그려집니다. 박스는 번호가 적힌 "위치 안내 이미지"로 모델에 함께 전달되므로 좌우가 뒤바뀌는 일이 줄어듭니다.
- **같은 구도의 사진 여러 장**: 한 장을 설정한 뒤 **이 설정을 전체에 적용**을 누릅니다. 1인 사진이 많으면 하단의 **1번 인물 일괄 지정**을 쓰세요.
- **결과 비교**: 결과를 클릭하면 뷰어가 열립니다. `1` 결과, `2` 비교 슬라이더, `3` 나란히 보기, `←/→`로 이동합니다.
- **ZIP 다운로드**: 작업 현황에서 묶음 단위로 결과를 한 번에 받습니다.
- **+1장 더**: 마음에 들지 않으면 같은 설정으로 한 장 더 생성합니다.

## 고급 설정 (환경 변수)

| 변수 | 설명 |
| --- | --- |
| `PORT` | 기본 3000 |
| `HOST` | 기본 `127.0.0.1` (이 PC에서만 접속). 인증 기능이 없으므로 `0.0.0.0`으로 공개하지 마세요. |
| `DATA_DIR` | 데이터 저장 위치 (기본 `./data`) |
| `GOOGLE_APPLICATION_CREDENTIALS` | 서비스 계정 JSON 경로 (앱에서 등록한 키가 없을 때 사용) |

## 구조

```
server/
  index.js    Express API, 정적 파일, ZIP 다운로드
  queue.js    작업 큐: 동시성, 분당 제한, 백오프, 429 쿨다운, 차단 재시도
  imageops.js 마스킹 영역 원본 복원 / 여백 잘라내기 (sharp)
  vertex.js   서비스 계정 인증 + Vertex AI generateContent 호출, 오류 분류
  prompts.js  변환 / 채색 / 인페인트 / 자유 모드 / 외형 분석 프롬프트 생성
  store.js    JSON 파일 저장소 (설정, 키, 캐릭터, 작업)
public/       프론트엔드 (빌드 과정 없는 ES 모듈)
```
